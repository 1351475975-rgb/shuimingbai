## 产品是什么

「GEO软文项目经理」是一套面向自媒体运营者、企业市场部和内容代理商的 **AI 内容生产流水线**。

它不是简单的「写一篇文章」，而是模拟真实内容团队的分工：

| 角色 | 做什么 |
|------|--------|
| **项目经理（PM）** | 与你沟通行业/产品/红线，建档后每日审核选题与合规 |
| **选题编辑** | 从微博/百度/知乎热榜筛选可写话题 |
| **GEO 写手** | 按生成式引擎优化（GEO）规则写结构化软文 |
| **配图编辑** | 自动生成封面、正文配图、小红书竖图 |
| **分发编辑** | 输出各平台适配版文案（长文/短文案/图文脚本） |

**日产 1 篇**，成本约 ¥0.01–0.3（DeepSeek API）。

## 解决什么问题

| 痛点 | 本产品怎么做 |
|------|-------------|
| 不知道写什么 | 每日热榜 + PM 选题审核 |
| 软文容易被平台限流/驳回 | PM 合规审查，不合规自动打回重写 |
| 同一篇文章要改 20 遍 | 一次生成，自动适配各平台格式 |
| AI 搜索时代 SEO 不够用 | 内置 GEO 规则：问答体、数据引用、结构化排版 |
| 高危平台封号 | 小红书/抖音/快手/视频号 **只生成素材，不自动发送** |

## 核心功能

### 1. 项目经理建档与审查

首次使用时，PM 会引导你填写：

- 行业、产品/服务、目标读者
- 品牌口吻、卖点、软文植入角度
- 合规红线（禁用词、广告标注要求）

之后每日自动执行：

- **选题审查**：热榜话题能不能写、从什么角度写
- **发稿审查**：广告标识、虚假宣传、敏感内容 → 不通过则打回重写（最多 2 次）

### 2. GEO 结构化软文

针对豆包、DeepSeek、通义等 AI 搜索场景优化，而非传统关键词堆砌：

- 问答式标题（是什么 / 怎么做 / 值不值）
- 总分总正文 + 列表/表格
- 嵌入可核查数据与来源标注
- 自然植入产品，标注 `[合作推广]` / `[广告]`

### 3. 图文一体输出

每篇产出包含：

| 素材 | 规格 |
|------|------|
| 主文 | Markdown 长文 1200–1800 字 |
| 封面 | 16:9 + 1:1 两版 |
| 正文配图 | 2–4 张 |
| 小红书竖图 | 3 张（3:4） |
| 平台文案 | 20 份适配版 |

### 4. 多平台分级策略

按风控强度自动分流，**不承诺全自动零风险发文**：

| 档位 | 平台 | 策略 |
|:---:|------|------|
| ★★★★★ | 小红书、抖音、快手、视频号 | **仅生成**图文包，人工发布 |
| ★★★★ | 知乎、微博、B站专栏等 | 生成草稿素材 |
| ★★–★★★ | CSDN、掘金、头条号、百家号等 | 生成草稿素材 |
| ★ | WordPress 自建站 | 支持 API 自动发草稿（需自行配置） |

## 常见问题

**Q：只需要 DeepSeek Key 就能跑吗？**  
A：是。热榜免费、配图可用占位图，核心流程只需一个 LLM Key。

**Q：能自动发到小红书吗？**  
A：不能自动发。小红书风控极高，本产品只生成文案和图片，需你手动发布。

**Q：PM 审查靠谱吗？**  
A：PM 是 AI 规则 + LLM 双重审查，能拦截大部分合规问题，但**建议人工终审后再发**。

**Q：换行业怎么办？**  
A：重新运行 `init_pm.py` 更新品牌档案即可，框架不用改。

**Q：和传统 SEO 工具有什么区别？**  
A：传统 SEO 优化搜索引擎排名；GEO 优化 AI 搜索（豆包/DeepSeek/ChatGPT）中的引用和推荐概率。
