# 税明白 — 产品共识文档

> 最后更新：2026-05-30  
> 状态：需求已对齐，待进入开发与内容产出阶段

---

## 一句话定位

帮普通人（上班族、自由职业者）用大白话搞清：**我现在的税务是什么情况**，再按需查看退税、副业、开票等具体事项。

**不是**专业记账/代账 SaaS，**不是**对标自记账。

---

## 目标用户（仅两种，不搞混）

| 类型 | 定义 |
|------|------|
| **普通上班族** | 有固定单位发工资，公司代扣个税 |
| **自由职业者** | 没有固定工资，主要靠自己接单/项目赚钱 |

**注意：**「上班 + 偶尔副业」不是第三种身份，而是上班族的可选「其它收入」字段。

---

## 核心产品逻辑

```
第1步：选身份 → [普通上班族] / [自由职业者]

第2步：填收入（按身份不同）
  - 上班族：月均工资 + 五险一金 + 年终奖 + 可选其它收入
  - 自由职业：项目/接单收入（可多条），不问月工资

第3步：填扣除项（租房/房贷、子女教育、赡养老人、继续教育等）

第4步：税务情况总览（核心页）
  - 人话输出 3～5 条结论
  - 上班族与自由职业者使用不同话术模板

第5步：具体事项入口（按需点击）
  - 上班族：[退税] [其它收入要不要管]
  - 自由职业：[这单要不要交税] [客户要开票怎么办]
```

**原则：** 先摸清税务全貌，再进退税/副业/开票等分支。退税是上班族的重要钩子，但不作为首页唯一入口。

---

## 收入问卷规则

### 普通上班族

- **月均工资（税前）**：必填，具体数字
- 提示：换工作或收入不稳定时，填**近 12 个月平均月薪**
- **五险一金（个人部分）**：选填；可提供「按工资 10.5% 估算」
- **年终奖/十三薪（全年总额）**：选填，无则填 0
- **其它收入**：选填，可多条添加（类型、金额、频率：一次性/每月/每季度）

### 自由职业者

- 不填「月工资」
- 按项目/接单填写，可多条（类型、金额、频率）
- 提示：可按近 12 个月加总或按月平均填写

---

## 测算与准确性

- 工资：累计预扣法 + 专项附加扣除
- 劳务报酬：4000 以下减 800，以上减 20%
- 退税：对比已预扣与全年应缴，输出「可能退 / 可能补 / 不确定」
- 页脚免责声明：**仅供参考，以「个人所得税」App 及税务机关为准**
- 第一版不对接税务局 API

---

## 收费模式

| 阶段 | 规则 |
|------|------|
| 试用 | 免费 7 天，**每天限 3 次**税务测算 |
| 付费 | **¥9.9/月** 或 **¥59/年**（推年付） |
| 付费价值 | 无限次测算、申报提醒（如 3 月/5 月汇算）、全部功能 |

## 第一版范围

### 做

- 两种身份问卷 + 收入/扣除填写
- 税务情况总览页
- 分支模块：退税指引、其它收入/副业、开票指引
- 基础短文内容（大白话，非术语）
- 试用次数限制 + 付费墙

### 不做（第一版）

- 完整记账系统
- 代申报、代开发票
- 个体户注册代办
- 对接税务局 API

---

## 推广与角色

- 创始人作为**第一个用户**（边用边改）
- 内容引流：小红书 / 知乎，主题如「同事退税了为什么我沒有」「打工人 3 月别忘了这件事」
- 后期变现可拓展：个体户注册/代账导流（非第一版重点）

---

## 竞品差异

| 产品 | 差异 |
|------|------|
| 自记账 | 面向已有个体户，做记账+报税；我们面向「还没搞懂的人」 |
| 个人所得税 App | 官方办事工具；我们做「解释器 + 导航」 |
| 免费计算器网页 | 只有算数；我们做「全貌诊断 + 路径 + 提醒」 |
