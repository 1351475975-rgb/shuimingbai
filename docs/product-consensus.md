# 税明白 — 产品共识文档

> 最后更新：2026-06-10  
> 状态：需求已对齐，主流程已统一，待进入内容与开发阶段

---

## 一句话定位

帮普通人（上班族、自由职业者）**填一张表、算清楚税务**：用大白话告诉你现在是什么情况，退税/副业/开票只是结果里按需展开的具体说明。

**不是**专业记账/代账 SaaS，**不是**对标自记账。

**核心体验只有一件事：** 选身份 → 填收入与扣除 → 出结果。没有两条线、没有多个独立入口。

---

## 目标用户（仅两种，不搞混）

| 类型 | 定义 |
|------|------|
| **普通上班族** | 有固定单位发工资，公司代扣个税 |
| **自由职业者** | 没有固定工资，主要靠自己接单/项目赚钱 |

**注意：**「上班 + 偶尔副业」不是第三种身份，而是上班族的可选「其它收入」字段。

---

## 核心产品逻辑（一条主流程）

用户只做**一次测算**，从头到尾是一条线：

```
首页
  └ 两个大按钮选身份，点完直接进入填表（不是进不同产品）

填表（同一套流程，字段按身份变化）
  ├ 第1屏：收入（上班族问工资+可选其它收入；自由职业问项目/接单）
  ├ 第2屏：扣除项（租房/房贷、子女教育、赡养老人、继续教育等）
  └ 底部：[生成我的税务情况]  ← 唯一提交动作

结果页（测算输出，不是另一个功能）
  ├ 顶部：关键数字（全年大概交多少 / 可能退还是补）
  ├ 中部：3～5 条人话结论（按身份用不同话术）
  └ 下部：根据你填的内容，自动展开相关说明（不是让用户再选一次）
        · 有扣除项 / 上班族 → 展开「退税」说明
        · 填了其它收入 → 展开「这笔收入要不要管」
        · 自由职业 → 展开「要不要交税 / 客户要开票怎么办」
```

### 关键原则（避免拆成两个产品）

| 以前容易搞混的 | 正确理解 |
|----------------|----------|
| 「先总览，再进退税模块」 | 总览和退税是**同一张结果页**的不同区块 |
| 「退税是入口 / 钩子是入口」 | 退税是**内容引流话题**，产品入口永远是「开始测算」 |
| 「身份、填表、计算」分开讲 | 这是**同一次操作的三段**，不是三个功能 |
| 用户手动点 [退税] [副业] [开票] | 系统根据填表**自动判断展示哪些区块**，用户可展开细看 |

**推广话术可以用「同事退税了你为什么没有」引流，但打开产品后仍是：选身份 → 填表 → 看结果。**

## 收入问卷规则

### 普通上班族

- **月均工资（税前）**：必填，具体数字
- 提示：换工作或收入不稳定时，填**近 12 个月平均月薪**
- **五险一金（个人部分）**：选填；可提供「按工资 10.5% 估算」
- **年终奖/十三薪（全年总额）**：选填，无则填 0
- **其它收入**：选填，可多条添加（类型、金额、频率：一次性/每月/每季度）

### 自由职业者

- 不填「月工资」
- 按项目/接单填写，可多条（类型、金额、频率）
- 提示：可按近 12 个月加总或按月平均填写

---

## 测算与准确性

- 工资：累计预扣法 + 专项附加扣除
- 劳务报酬：4000 以下减 800，以上减 20%
- 退税：对比已预扣与全年应缴，输出「可能退 / 可能补 / 不确定」
- 页脚免责声明：**仅供参考，以「个人所得税」App 及税务机关为准**
- 第一版不对接税务局 API

---

## 收费模式

| 阶段 | 规则 |
|------|------|
| 试用 | 免费 7 天，**每天限 3 次**税务测算 |
| 付费 | **¥9.9/月** 或 **¥59/年**（推年付） |
| 付费价值 | 无限次测算、申报提醒（如 3 月/5 月汇算）、全部功能 |

## 页面结构（第一版 3 页）

| 页面 | 内容 |
|------|------|
| **首页** | 一句话说明 + [我是上班族] [我是自由职业者] → 点选即进入填表 |
| **填表页** | 分步表单（收入 → 扣除），底部固定「生成我的税务情况」 |
| **结果页** | 测算数字 + 人话结论 + 按条件自动展开的说明区块 |

没有独立的「退税页」「副业页」作为第二入口；这些内容嵌在结果页里，或从结果页内链到短文详情。

---

## 第一版范围

### 做

- 一条主流程：选身份 → 填表 → 测算 → 结果
- 税务计算引擎（工资累计预扣 + 劳务报酬 + 扣除项 + 退/补判断）
- 结果页内嵌：退税说明、其它收入说明、开票说明（按填表条件显示）
- 基础短文内容（大白话，从结果页链出）
- 试用次数限制 + 付费墙（限制的是「测算次数」，不是某个子功能）

### 不做（第一版）

- 完整记账系统
- 代申报、代开发票
- 个体户注册代办
- 对接税务局 API

---

## 推广与角色

- 创始人作为**第一个用户**（边用边改）
- 内容引流：小红书 / 知乎，主题如「同事退税了为什么我沒有」「打工人 3 月别忘了这件事」
- 后期变现可拓展：个体户注册/代账导流（非第一版重点）

---

## 竞品差异

| 产品 | 差异 |
|------|------|
| 自记账 | 面向已有个体户，做记账+报税；我们面向「还没搞懂的人」 |
| 个人所得税 App | 官方办事工具；我们做「解释器 + 导航」 |
| 免费计算器网页 | 只有算数；我们做「全貌诊断 + 路径 + 提醒」 |
